---
name: Write Email
description: Compose and send an email to a specified recipient.
---
To write an email, compose a message to a specified recipient with a subject line and body. Delivery is done by placing the file in the recipient's inbox directory.

To deliver an email, write the file in the recipient's inbox directory: `.agents/office/email/<recipient-name>/`. Each email should be saved as a separate file with the `.email.md` extension. The filename should include the date and a brief description of the email's content for easy reference (e.g., `2024-06-01-project-update.email.md`).
