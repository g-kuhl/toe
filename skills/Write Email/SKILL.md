---
name: Write Email
description: Compose and send an email to a specified recipient.
---
To write an email, use the `Write Email` skill to compose a message to a specified recipient. You will need to provide the recipient's email address, a subject line, and the body of the email. Once you have composed the email, you can send it to the recipient.

To send an email write the file in the recipient's inbox directory: `.agents/email/<recipient-name>/`. Each email should be saved as a separate file with the `.email.md` extension. The filename should include the date and a brief description of the email's content for easy reference (e.g., `2024-06-01-project-update.email.md`).
